# Spanish reviewer brief — Civica SNAP launch

**Sent:** [date when emailed]

## Why this is a hard launch blocker

CA Community College student population is ~30% Spanish-dominant. Pilot data integrity requires the ES locale to ship live — English-only launch is not a "pilot," it's a self-selected non-Hispanic sample that invalidates Civica's PER reduction claim to CDSS.

**Fallback if no reviewer by 2026-05-26:** delay pilot launch. Do NOT ship English-only to CCC students.

## Scope

- Review 106 short UI strings in a shared Google Sheet / Markdown / Notion doc
- Mark each as: accept / edit (provide new text) / reject (explain)
- Tone target: plain, specific, adult — NOT bureaucratic Spanish
- Ideal candidate: someone who's reviewed government / benefits / nonprofit Spanish before
- Deliverable: marked-up doc + 15-min call to walk through edits

Strings source: `packages/snap-compliance-copy/data/*.json` + the new `data/exemption-copy.json` from Session A (LPIE bilingual copy).
