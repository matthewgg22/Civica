# Coordinator kit

Onboarding materials for campus basic needs coordinators referring CCC and CSU students to Civica for CalFresh enrollment.

## Contents

- [`student-overview.md`](./student-overview.md) — One-page student handout. Print double-sided or send as a PDF. Audience: a student who has never heard of Civica.
- [`coordinator-guide.md`](./coordinator-guide.md) — Coordinator onboarding for the navigator dashboard, including the manual BenefitsCal fallback SOP. Audience: a campus coordinator logging in for the first time.

## How to use

Read `coordinator-guide.md` end-to-end (about 10 minutes), log into the dashboard with the credentials Matthew provided, then hand `student-overview.md` to the first student who walks into your office.
