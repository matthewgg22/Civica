# CEO Plan: Demeter AI — the pivot to a single public SNAP-answers chatbot

## The Pivot (philosophy)

Mae is renamed **Demeter AI** and becomes the company's sole product focus: a public
web page with a chatbot whose one job is to be the best source of information for
SNAP questions and applications in any state. Everything else Civica built — iOS app,
caseworker mode, submission rail, EBT features, offers — is PARKED (not deleted;
branches and code remain, no further investment this phase).

**The goal is explicitly NOT a self-sustaining business.** Demeter is a
university-aligned social-impact play designed to hit the early benchmarks that
unlock school and prize funding: Harvard PIC, SIFF, Echoing Green, Okta for Good,
Westly. The timeline, precisely: **live in August**; the three-month test runs
August–November; readout lands before the earliest prize deadline. "100+ CBO
supporters" is the campaign goal for the test run — the August bar is the supporter
program LIVE with the first cohort signed (prestige play, not a revenue play).

## Why this can win (differentiation, verified against the Aug-2026 landscape)

The field is crowded at the surface: mRelief's "Johnnie" chatbot, Propel's recipient
chatbot, Anthropic × Code for America's caseworker pilot (May 2026), Maximus's state
error-prevention tool. Demeter's lane is different and defensible:

1. **Verified state corpora, adversarially fact-checked.** Five states live
   (CA/WA/TX/NY/GA — OR sources fetched), each with a PROVENANCE trail, citation
   verifier, freshness cliffs, and a refute-gate verdict (e.g. GA: 84 claims checked,
   0 fabricated). No competitor can show this.
2. **A public scoreboard exists**: Public Benefits Bench (vals.ai). A published
   benchmark run converts "best source of information" from slogan to measurement —
   the single most fundable artifact for prize judges.
3. **Honest-coverage UX**: verified-state badges vs federal-floor labeling turns
   partial coverage into a trust feature and each new state pack into visible
   product momentum during the test run.

## Vision

### 10x Check (surfaced, mostly deferred by design)
The 10x version is "the answer layer for all means-tested benefits" (SNAP → Medicaid
→ WIC → LIHEAP) with an API other orgs build on. Deliberately NOT this phase — the
pivot's power is subtraction. The architecture (state packs, citation verifier)
already points there; nothing in this plan forecloses it.

## Accepted Scope (the launch set)

1. **Rename Mae → Demeter AI** across code, routes, and docs. The engine moves from
   `apps/dashboard/lib/mae` to a shared **`packages/demeter-engine`** consumed by both
   apps (this is the integration mechanism for the public page — ~1 day, estimated
   separately). `/api/mae` keeps a compatibility redirect for 30 days (sole consumer
   today is the dashboard's own UI), then dies.
2. **Public chat page** (in `apps/web`, which already has Google OAuth): anonymous
   rate-limited Q&A; signed-in users get history (last 50 conversations, 90-day
   retention; anonymous conversation HISTORY is never retained or shown — question
   text is retained server-side 30 days for evaluation, then aggregate-only); streaming
   answers with citations. **Cost/abuse posture:** $200/month LLM spend ceiling,
   enforced server-side per request (over ceiling → graceful "at capacity" response);
   rate limiting via apps/web's EXISTING per-route limiter pattern (the auth and
   lead-capture helpers — NOT the PR #248 Workers bindings, which live on
   enrollment-api and are unreachable from Vercel); retrieval-grounded answering is
   the prompt-injection posture (the system prompt treats user text as questions,
   never instructions; no tools are exposed). **Privacy (launch-blocking):**
   anonymous question text stored 30 days for eval purposes, then aggregate-only;
   signed-in history per item 2's retention; /privacy page updated to say exactly
   this before go-live.
3. **Bilingual EN/ES answers** — language auto-detected from the message (toggle
   overrides). **Verification order is fixed: retrieve + verify citations on the
   English corpus first, then compose the ES answer carrying the same verified
   citations** — the "0 fabricated" property is preserved because verification never
   runs on translated text. ES paraphrase eval cases (≥10) added to the frontdoor
   harness.
4. **Distress gate**: keyword/phrase list v1 (EN + ES) → expedited-SNAP rights +
   211/food-bank pointers first, then the answer; reuses the #594 expedited engine
   content; ≥10 distress eval cases in the frontdoor harness (matching the ES rigor).
5. **State selector with honest badges**: "✓ Verified" (pack states) vs "Federal
   guidance" (fallback), each linking to the verification page. The federal-floor
   path ALREADY EXISTS (`getStatePack(unknown)` → null → the 415-chunk federal 7 CFR
   corpus; every state's eval suite carries a federal-control case) — launch task is
   to VERIFY it end-to-end from the new UI, not to build it.
6. **Public "How we verify" page**: per-state provenance summaries (sources, gate
   verdicts, freshness dates) rendered from the PROVENANCE/pack data.
7. **Public Benefits Bench run** + published scorecard (with honest per-state
   framing). Third-party dependency handled up front: confirm the vals.ai submission
   path in week 1; FALLBACK if not listed by November = self-run public evaluation on
   a published question set with published methodology (still a judge-verifiable
   artifact).
8. **Supporter program**: supporter definition (verbatim, used everywhere):
   *"A Demeter Supporter is a community organization that endorses free, accurate
   SNAP guidance and shares Demeter with the people it serves."* Free. Lightweight
   sign-on form + ENDORSEMENT LETTER template (deliberately not called an MOU — 'partner'
   stays reserved for contracted/data-sharing relationships), public /supporters wall,
   one SVG badge. Recruitment
   is a staffed workstream, not a hope: Matthew owns it; channels = the CBO/navigator
   network from prior UAT + Project Bread contacts + CA food-bank/nutrition-outreach
   lists. Calibrated targets: FLOOR 2 signed/week (the ≥25 pass bar), STRETCH 10/week
   (the 100+ campaign goal). Outreach starts THIS WEEK, parallel to the build — CBO
   signature turnaround is historically this org's slowest dependency — and the
   August bar for "first cohort" is ≥3 signed supporters.
9. **CBO Founding tier ($20/mo)** — exists as a COMMITMENT SIGNAL and a live test of
   the reimbursement pathway, not revenue (that one sentence is the reconciliation
   with the non-revenue framing). Deliverable without any org model: "Founding" flag
   on the wall, priority-support email, a quarterly usage letter the CBO can attach
   to its own funding reports, and first access to the phase-2 dashboard. Stripe
   payment link + manual onboarding; merchant of record = VoteNow Advocacy Foundation
   (the entity Civica operates under — confirm with counsel during week 1). Paying
   CBOs ARE counted on the wall (flagged "Founding"); the supporter count includes
   them. Per-CBO referral links/codes are the usage-attribution mechanism (no org
   model needed): the "CBO usage" metric counts sessions arriving via a CBO's link. Reimbursement wording limited to
   "may qualify as an allowable outreach cost under your state's SNAP outreach plan
   (50% federal share today; 25% from FY2027)" — never an unconditional "eligible
   for reimbursement" claim.
10. **Three-month-test instrumentation**: reuse the #590 cohort event schema
    (questions asked, state mix, citation clicks, feedback thumbs, CBO usage via
    referral codes, and citation-verifier pass/fail per answer — the event behind the
    97% target).
    Readout = shared doc weekly until week 4, page after that. **Success targets the
    prize applications will cite:** ≥1,000 questions answered; ≥25 signed supporters
    by the Nov 30 readout (100+ is the campaign goal, not the pass bar); ≥60% of
    questions in verified states; ≥97% citation-verifier pass rate in production; a
    published Public Benefits Bench score (or the named fallback); ≥5 CBO Founding
    orgs.

## Open compliance/positioning cautions (carried into deep review)

- The 25%-reimbursement framing requires contracted-subrecipient status under a state
  outreach plan — wording rule above is binding for all public copy.
- "Partner" vs "Supporter": public copy uses "supporter"; "partner" reserved for
  signed MOUs. Prize applications must survive diligence.
- Public chatbot for a vulnerable population: PII handling (existing pii.ts),
  no-advice disclaimer ("informational, not legal advice; confirm with your agency"),
  and the distress gate are launch-blocking, not nice-to-have.
